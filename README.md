# STLoD-GS project page

[Project page](https://cmlab-korea.github.io/STLoD-GS/) · [Code repository](https://github.com/CMLab-Korea/arXiv-STLoD-GS)

Serve this directory as the root of the GitHub Pages site. The entry point is `index.html`. The demo videos are in `videos/`, and page scripts, figures, fonts, and institutional logos are in `assets/`. The ETRI and Chung-Ang University affiliation icons and CMLab wordmark come from the [MoRel project page](https://cmlab-korea.github.io/MoRel/).

Set `arxivId` in `assets/publication.js` when the identifier is assigned. This activates the arXiv button and updates BibTeX. The pageview badge loads on the public project domain.
